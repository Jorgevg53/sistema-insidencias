# Prototipo navegable

`prototipo_teschi.html` es un prototipo de alta fidelidad del sistema en un solo archivo: todas las pantallas
con el diseño institucional (verde TESCHI) y datos de ejemplo. No necesita XAMPP ni base de datos.

## Cómo abrirlo

Haz doble clic en `prototipo_teschi.html` (se abre en el navegador) o arrástralo a una ventana de Chrome, Edge o Firefox.

- En el inicio de sesión hay botones para entrar como **Administrador, Coordinador, Docente o Estudiante**.
- La barra oscura superior ("Ver como") cambia de usuario en cualquier momento; el menú se ajusta al rol.
- Los cambios se guardan solo en ese navegador. **Reiniciar datos** regresa al ejemplo original.

## Qué incluye

Iniciar sesión, recuperar y restablecer contraseña, Dashboard, Registrar incidencia, Mis incidencias,
Asignadas a mí, Todas las incidencias (filtros y paginación), Detalle (gestionar, reclasificar, atender,
comentar, cancelar y seguimiento), Notificaciones, Reportes (gráficas calculadas), Usuarios (alta, edición,
activar/desactivar y enlace para restablecer contraseña), Catálogos, Mi perfil y la vista previa del ticket.

## Diferencias con el sistema real

- Acepta cualquier contraseña y los datos son de ejemplo.
- "Exportar a Excel" solo muestra un aviso y las evidencias solo muestran el nombre del archivo.
